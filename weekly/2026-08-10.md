## 本周重点解读

### 1. Deep Research 的排序目标正在从“相关”升级为“集合是否足够完成任务”

RubricRanker 是本周最值得关注的工作。传统 reranker 逐文档判断 relevance，但 Deep Research 往往需要一组互补证据：有的负责定义、有的给数据、有的提供反例或权威出处。因此更合理的监督信号应描述整个文档集合是否覆盖需求，而不是只判断单篇文档像不像 query。

可直接落地的方式：对每个复杂 query 先生成层次化 search rubric，再对候选文档集合计算 coverage、authority、redundancy、diversity、answerability 等 reward，用于 SFT/RL 训练或在线 rerank。

### 2. Agentic Search 正在形成“Agent ↔ Retriever”共同训练闭环

Agentic-R 和 RRPO 指向同一个变化：检索模块不能继续作为固定黑盒。Agent 产生的新 query、最终任务是否成功、生成答案是否正确，都可以反向成为 retriever/reranker 的训练信号。

相比传统“Embedding → Reranker → LLM”静态链路，更值得尝试的是：

- rollout Agent trajectory；
- 记录每轮 query、候选文档、选择结果和最终答案；
- 用 end-to-end success 构造 passage/document utility；
- 周期性更新 retriever/reranker；
- 再用新 retriever rollout 更强 trajectory。

这实际上接近搜索场景中的 policy iteration。

### 3. Reranker 的 domain mismatch 可能比模型能力差距更致命

SciRet 的实验提醒了一个常被忽略的问题：一个在 MS MARCO 上很强的 Cross-Encoder，放到科学文献语料里未必继续有效。实际生产系统应同时评估：

- Recall@K / NDCG / MRR；
- 最终答案 correctness / faithfulness；
- reranker latency 与 GPU cost；
- 不同 domain 的增益或退化；
- reranker depth 从 Top20、Top50、Top100 的边际收益。

因此“更大 reranker”不应成为默认答案，domain data + task-aligned reward 往往更重要。

### 4. RAG 与模型参数化记忆之间的边界继续变模糊

RING 尝试把 retrieval policy 和外部知识一起内化进模型，使模型自己完成 parametric search。这不代表外部搜索会消失，但给出了一种新的系统拆分方式：稳定、频繁访问的知识可以进入 Memory Expert；实时变化、长尾、需要引用的知识继续走外部 Search/RAG。

未来更可能出现 Hybrid Memory：参数化 memory + vector/keyword search + web search，由 Agent 根据任务决定走哪种 memory source。

### 5. MCP 新规范进一步推动 ToolHub 从“协议适配层”变成 Agent 基础设施

无状态 MCP 对大规模生产部署非常关键：请求可以被任意实例处理，gateway 可以基于 header 做 routing/authorization，tools/list 可以缓存，长任务交给 Tasks。对于拥有大量 ToolSpec / MCP Server 的系统，后续重点已经不只是“协议能不能通”，而是 Tool Retrieval、Schema 裁剪、权限边界、缓存与可观测性。

## 建议优先实践的三个实验

1. **Deep Research Rubric Reranker**：给复杂 query 自动生成 5–10 条 rubric，对比传统 Cross-Encoder、LLM pointwise rerank、listwise rerank、rubric-based rerank 的最终任务成功率、文档覆盖率与 token 成本。
2. **Agent-Retriever Policy Iteration**：从现有 Agent trajectory 中提取每轮搜索 query 和最终 success label，训练一个 end-to-end utility retriever，再重新 rollout，观察检索轮数、答案成功率和平均 token 是否同步改善。
3. **Domain-aware Reranker**：在通用 Cross-Encoder 基础上加入业务 hard negative / teacher score / downstream judge reward，对比“换更大模型”和“做领域后训练”哪个 ROI 更高。

## 本周趋势判断

- **Deep Research 正把 Search/Rerank 从 relevance optimization 推向 task utility optimization。**
- **Agentic Search 的 Retriever 会逐渐成为可训练 policy，而不是固定基础设施。**
- **RAG 的核心优化指标正在从 Recall/NDCG 转向最终任务成功率、证据集合质量和总成本。**
- **参数化 Memory 与外部 Retrieval 将长期共存，并由 Agent 动态路由。**
- **多模态后训练正在从单纯 instruction tuning 走向 preference/RL/on-policy distillation 与 Agent 行为塑形。**
